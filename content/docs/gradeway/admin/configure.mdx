Gradeway splits its configuration into three TOML files, all created inside Gradeway's data
directory (`plugins/gradeway/`) the first time it loads:

| File            | Purpose                                                                          |
| --------------- | -------------------------------------------------------------------------------- |
| `config.toml`   | General settings: message appearance, import limits and default role handling.   |
| `drivers.toml`  | Which database and messaging [drivers](/gradeway/admin/drivers) to use.          |
| `platform.toml` | Settings that only apply to the platform you're running (Paper, Velocity, ...).  |
| `.env`          | Connection credentials and other variables read by the drivers (create it yourself). |

Every TOML file carries a `version` field. Gradeway bumps it automatically when a newer release
adds options, so you don't need to touch it yourself.

## config.toml

```toml title="config.toml"
version = 2
# Defines the prefix that is prepended to messages sent by Gradeway.
# Supports MiniMessage formatting.
prefix = "<gradient:#ed751f:#e89e1e>Gradeway</gradient> <dark_gray>›</dark_gray> "
# Defines the primary color used throughout Gradeway messages.
# Must be a hex color code.
primaryColor = "#ed751f"
# Defines the secondary color used throughout Gradeway messages.
# Must be a hex color code.
secondaryColor = "#e89e1e"
# Defines the maximum decompressed size, in bytes, allowed when importing a backup or migration file.
# Protects against decompression-bomb archives that expand to consume excessive memory once decompressed.
# Increase this if your server has a very large dataset and legitimate imports are being rejected.
maxImportSizeBytes = 2147483648

# Controls when players automatically receive the default role.
# The default role is selected with '/gradeway role default set <role>'.
[defaultRole]
  # Assigns the default role to players when they join for the first time
  # and also makes it their primary role.
  assignOnFirstJoin = true
  # Assigns the default role on every join to players who have no primary role.
  # This also covers existing players, but re-applies the default role after
  # their primary role has been cleared.
  assignWhenNoPrimaryRole = false
```

### Default role

The **default role** is handed out to players automatically when they join, and becomes their
primary role. Pick it with `/gradeway role default set <role>`, see
[Commands](/gradeway/commands#default-role).

- `assignOnFirstJoin` gives the default role to players joining for the very first time.
- `assignWhenNoPrimaryRole` additionally gives it, on every join, to any player without a primary
  role. This also covers players that already existed before you configured a default role.

<Callout type="idea">
  If several roles are flagged as default (`/gradeway role modify <role> setDefault true`), the one
  with the highest weight is used, ties are broken by name.
</Callout>

## drivers.toml

```toml title="drivers.toml"
version = 1

[database]
  # Defines the database type that Gradeway should use.
  # Use the 'id' of the installed database driver.
  driver = "postgres"
  # Defines the prefix for all Gradeway database tables.
  # Set the value to an empty string to not use a prefix.
  prefix = "gradeway_"

[messaging]
  # Controls whether messaging should be enabled or disabled.
  # If messaging is disabled, data can no longer be synchronized in real time.
  enabled = false
  # Defines the type of messaging service.
  # Use the 'id' of the installed messaging driver.
  driver = ""
```

## Environment variables

Drivers read their connection settings (host, port, credentials, encryption keys, ...) from
environment variables, see [Drivers](/gradeway/admin/drivers) for the variables each driver
supports. Gradeway looks a variable up in the following sources, the first one that defines it
wins:

1. The `.env` file inside Gradeway's data directory (`plugins/gradeway/.env`).
2. JVM system properties, passed with `-Dkey=value` when starting the server or proxy.
3. The system environment variables of the running process.

```dotenv title=".env"
GRADEWAY_DATABASE_HOST=localhost
GRADEWAY_DATABASE_PORT=5432
GRADEWAY_DATABASE_NAME=gradeway
GRADEWAY_DATABASE_USER=gradeway
GRADEWAY_DATABASE_PASSWORD=change-me
```

<Callout type="warn">
  The `.env` file contains credentials. Make sure only the user running the server or proxy can
  read it, and never commit it to a public repository.
</Callout>

<Callout type="info">
  Upgrading from **0.2.x**? The `[database.variables]`, `[messaging.variables]` and `[env]`
  sections are gone. Move your variables into `plugins/gradeway/.env` (or the system environment),
  and move your `database`/`messaging` settings from `config.toml` into `drivers.toml`.
</Callout>
