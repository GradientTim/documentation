Gradeway needs a **database driver** to store its data, and optionally a **messaging driver** to
sync data in real time across servers, see [Messaging](/gradeway/admin/messaging). Drop the
driver's `.jar` into the `drivers/` folder and set its `id` as `database.driver` or
`messaging.driver` in `config.toml`, see [Configuration](/gradeway/admin/configure).

Each driver reads its connection settings from environment variables. Every driver exposes a
generic name (e.g. `GRADEWAY_DATABASE_HOST`) alongside a driver-specific alias (e.g.
`GRADEWAY_POSTGRES_HOST`), whichever is set first wins. A variable marked **required** has no
fallback and must be set, otherwise Gradeway throws an error on load; a variable marked
**optional** may be left unset, in which case the listed default (if any) is used instead.

Looking to build your own driver instead? See [Building a Driver](/gradeway/dev/drivers#building-a-driver-module).

## Official Drivers

These drivers are built and maintained in the [Gradeway repository](https://github.com/GradientTim/gradeway)
and are attached to every [release](https://github.com/GradientTim/gradeway/releases).

### Database

| ID          | Name                                                                                                    | Environment Variables                                                                                                                                                                                                                                                                                                          |
| ----------- | --------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `h2`        | [H2](https://github.com/GradientTim/gradeway/tree/main/driver-database-h2)                                 | `GRADEWAY_DATABASE_FILE` / `GRADEWAY_H2_FILE` (required)<br/>`GRADEWAY_DATABASE_USER` / `GRADEWAY_H2_USER` (optional)<br/>`GRADEWAY_DATABASE_PASSWORD` / `GRADEWAY_H2_PASSWORD` (optional)                                                                                                                                    |
| `mariadb`   | [MariaDB](https://github.com/GradientTim/gradeway/tree/main/driver-database-mariadb)                       | `GRADEWAY_DATABASE_NAME` / `GRADEWAY_MARIADB_NAME` (optional, default: `gradeway`)<br/>`GRADEWAY_DATABASE_HOST` / `GRADEWAY_MARIADB_HOST` (optional, default: `localhost`)<br/>`GRADEWAY_DATABASE_PORT` / `GRADEWAY_MARIADB_PORT` (optional, default: `3306`)<br/>`GRADEWAY_DATABASE_USER` / `GRADEWAY_MARIADB_USER` (optional)<br/>`GRADEWAY_DATABASE_PASSWORD` / `GRADEWAY_MARIADB_PASSWORD` (optional) |
| `mysql`     | [MySQL](https://github.com/GradientTim/gradeway/tree/main/driver-database-mysql)                           | `GRADEWAY_DATABASE_NAME` / `GRADEWAY_MYSQL_NAME` (optional, default: `gradeway`)<br/>`GRADEWAY_DATABASE_HOST` / `GRADEWAY_MYSQL_HOST` (optional, default: `localhost`)<br/>`GRADEWAY_DATABASE_PORT` / `GRADEWAY_MYSQL_PORT` (optional, default: `3306`)<br/>`GRADEWAY_DATABASE_USER` / `GRADEWAY_MYSQL_USER` (optional)<br/>`GRADEWAY_DATABASE_PASSWORD` / `GRADEWAY_MYSQL_PASSWORD` (optional) |
| `oracle`    | [Oracle](https://github.com/GradientTim/gradeway/tree/main/driver-database-oracle)                         | `GRADEWAY_DATABASE_NAME` / `GRADEWAY_ORACLE_NAME` (optional, default: `gradeway`)<br/>`GRADEWAY_DATABASE_HOST` / `GRADEWAY_ORACLE_HOST` (optional, default: `localhost`)<br/>`GRADEWAY_DATABASE_PORT` / `GRADEWAY_ORACLE_PORT` (optional, default: `1521`)<br/>`GRADEWAY_DATABASE_USER` / `GRADEWAY_ORACLE_USER` (optional)<br/>`GRADEWAY_DATABASE_PASSWORD` / `GRADEWAY_ORACLE_PASSWORD` (optional) |
| `postgres`  | [PostgreSQL](https://github.com/GradientTim/gradeway/tree/main/driver-database-postgres)                   | `GRADEWAY_DATABASE_NAME` / `GRADEWAY_POSTGRES_NAME` (optional, default: `gradeway`)<br/>`GRADEWAY_DATABASE_HOST` / `GRADEWAY_POSTGRES_HOST` (optional, default: `localhost`)<br/>`GRADEWAY_DATABASE_PORT` / `GRADEWAY_POSTGRES_PORT` (optional, default: `5432`)<br/>`GRADEWAY_DATABASE_USER` / `GRADEWAY_POSTGRES_USER` (optional)<br/>`GRADEWAY_DATABASE_PASSWORD` / `GRADEWAY_POSTGRES_PASSWORD` (optional) |
| `sqlite`    | [SQLite](https://github.com/GradientTim/gradeway/tree/main/driver-database-sqlite)                         | `GRADEWAY_DATABASE_FILE` / `GRADEWAY_SQLITE_FILE` (required)                                                                                                                                                                                                                                                                    |
| `sqlserver` | [SQL Server](https://github.com/GradientTim/gradeway/tree/main/driver-database-sqlserver)                  | `GRADEWAY_DATABASE_NAME` / `GRADEWAY_SQLSERVER_NAME` (optional, default: `gradeway`)<br/>`GRADEWAY_DATABASE_HOST` / `GRADEWAY_SQLSERVER_HOST` (optional, default: `localhost`)<br/>`GRADEWAY_DATABASE_PORT` / `GRADEWAY_SQLSERVER_PORT` (optional, default: `1433`)<br/>`GRADEWAY_DATABASE_USER` / `GRADEWAY_SQLSERVER_USER` (optional)<br/>`GRADEWAY_DATABASE_PASSWORD` / `GRADEWAY_SQLSERVER_PASSWORD` (optional) |

<Callout type="idea">
  `sqlite` and `h2` are file-based and run embedded, without a host or port, they're a good fit
  for small servers or testing. Every other database driver expects a reachable server.
</Callout>

## Community Drivers

Drivers built and maintained outside the Gradeway repository. They aren't reviewed or supported
by the Gradeway maintainers, install them at your own risk.
